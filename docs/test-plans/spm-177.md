## Verification boundaries

From the backend worktree:

```sh
npm ci --ignore-scripts
npm test -- --runInBand
PGLITE_MODULE=/path/to/@electric-sql/pglite node --test tests/database/*.test.cjs
```

The SQL suite uses a reduced fixture reused from the existing SPM-36 isolated
schema and an in-memory PGlite engine. It does not load the complete hosted
schema, reproduce production RLS or test concurrent PostgreSQL clients. It
never reads private environment variables or connects to Supabase.

Hosted tests still need a separately authorized environment, namespaced
synthetic fixtures and cleanup. Required cases include two separate clients
assigning overlapping events to one Coordinator, one assignment racing a
reassignment, actual function grants/RLS and confirmation of both notification
recipients through the application. Do not infer these results from mocks.

The frontend retains main's working `/assignments` page and its supervision
and reassignment contracts while adding SPM-177 queue recovery.
